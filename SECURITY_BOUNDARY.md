# ReportOps GitHub Public-Safe Security Boundary

Status: R2 CURRENT

## Allowlist

Only information already suitable for public disclosure may be stored here:

- public-source URLs, publisher names, publication timestamps and data periods;
- short paraphrases of public facts and claims;
- public-market price/supply/demand/shipping/geopolitical observations;
- generic sector and value-chain implications;
- public-safe Daily templates, schemas and quality rules;
- public Current pointers for already published report cycles;
- Scheduled Chat bridge/checkpoint metadata.

## Denylist

Never store:

- JOVO/九丰-specific operating, contract, margin, capital-allocation or opportunity analysis;
- user-supplied/internal operating data, economics/model inputs or non-public assumptions;
- seller mandates, private projects, negotiations, MOU/LOI/contract screening information;
- internal Research Object state or full internal Lineage/Evidence registries;
- private Site access information, credentials, tokens or secrets;
- internal audit/debug logs, failed-attempt details or Work scratch paths;
- full third-party article text or paywalled content.

## Default rule

When uncertain whether a field is public-safe, do not commit it. Mark the field `PRIVATE_LAYER_REQUIRED` in the task result instead.

GitHub is a bridge, not Canonical Authority.
