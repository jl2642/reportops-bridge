# reportops-bridge

Public-safe runtime bridge for ReportOps scheduled Chat tasks.

This repository is **not** the ReportOps operational authority and must not contain private/internal company data, private Site access information, internal Research Objects, internal Lineage registries, model inputs, credentials, logs, or full third-party article text.

Its purpose is limited to:

- public-safe Daily runtime instructions and templates;
- machine-readable public Current pointers;
- structured public-source evidence packets;
- Scheduled Chat checkpoints and bridge status;
- public-safe Daily output cores used for later reconciliation/publishing.

Canonical operational state remains in the ChatGPT Library. GitHub is only a cross-task public bridge.

See `SECURITY_BOUNDARY.md` before adding any new field or file.
